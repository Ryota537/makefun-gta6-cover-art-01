Sunset Panel Studio — an offline web app that turns any photo and a caption into multi-panel cover art in the style of a neon-sunset poster, exported as a PNG to share. Pick a layout (Hero + Two, Grid 2 x 2, Tall Strip, Full Bleed), fill each panel with your own photo — cropped and positioned per panel — or with one of the painted scenes the app draws in code, choose a grade (Sunset, Neon Night, Palm Dusk, Vice Glow), letter the title in bold gradient capitals with a glowing subtitle, and export at 1080 x 1080, 1080 x 1350 or 1920 x 1080. Every image in the app is drawn procedurally on canvas — no photos, fonts or artwork are downloaded or shipped — and nothing leaves your machine: the app makes no network request at all.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
